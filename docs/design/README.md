# Оформление страницы раздела — исходники артбордов

Девять артбордов для канваса Claude Design плюс манифест раскладки.
Каждый `.dc.html` — самостоятельный HTML-файл: открывается в браузере как есть,
никакой сборки не требует.

## Что где

| Файл | Что показывает |
| --- | --- |
| `Main.dc.html` | колонка чтения: проза, схема иерархии памяти, врезка — светлая тема |
| `ReadingDark.dc.html` | то же в тёмной теме |
| `Contents.dc.html` | оглавление курса с прогрессом по заданиям |
| `ExerciseDefault.dc.html` | задание в исходном состоянии |
| `ExercisePass.dc.html` | задание зачтено — крупное число ускорения |
| `ExercisePassDark.dc.html` | то же в тёмной теме |
| `ExerciseError.dc.html` | ошибка компиляции с номером строки и, отдельно, сбой сервиса |
| `Benchmark.dc.html` | замер лестницы кэша с графиком |
| `Visualization.dc.html` | анимация кэш-линии |
| `canvas.json` | раскладка артбордов на канвасе и заметки |

## Направление

Лабораторный журнал, который считает. Проза — Literata (сериф для длинного
экранного чтения, полная кириллица), служебные подписи — IBM Plex Sans, код и
числа — JetBrains Mono. Виджеты оформлены как «фигуры» в научной статье: тонкая
рамка, ярлык-подпись сверху, без заливок и теней.

Единственное место, где допущена визуальная энергия, — момент зачёта: ускорение
набрано крупным моноширинным числом, левый край блока становится зелёным.

## Отношение к `web/static/style.css`

Имена CSS-переменных и классов сохранены один в один, чтобы не трогать JS.
Отличаются только значения:

- `--color-bg` — чистый белый заменён тёплой бумагой `#fdfcfa`;
- радиусы блоков `6px` → `2px`;
- добавлены три шрифтовых токена (`--serif`, `--sans`, `--mono`).

В тёмных артбордах токены заданы прямо на `:root`, чтобы файл выглядел тёмным
независимо от настройки смотрящего; в реальной таблице стилей те же значения
приходят из `@media (prefers-color-scheme: dark)`.

## Что здесь предложено, но в коде пока не решено

- В оглавлении показан прогресс по заданиям. Данные для этого уже пишутся в
  `localStorage` (`web/static/progress.js`), но нигде не отображаются.
- Схема иерархии памяти нарисована столбиками без точных чисел: раздел
  настаивает, что свои числа студент получает замером, поэтому картинка их не
  сообщает.
