# Модель процессора и размеры кэшей

`make up` перед запуском Docker Compose выполняет `python3 scripts/cache-info.py`.
Скрипт без внешних зависимостей записывает сведения о хосте в
`.runtime/cache-info.json`. Файл не коммитится и монтируется в runner только для чтения.

При прямом запуске Compose отчёт можно подготовить отдельно:

```sh
python3 scripts/cache-info.py
docker compose up -d --build
```

Linux: размеры читаются из sysfs для доступных процессу CPU, модель — из
`/proc/cpuinfo`. macOS: используется `sysctl`, отдельно для групп ядер.
Если контейнер не сообщает модель или размеры, runner использует отчёт хоста
при совпадении архитектуры. При переносе проекта на другой компьютер отчёт
нужно создать заново. Неизвестные размеры не подставляются из справочника.

`/api/cache-info` возвращает сведения о машине, выполняющей замеры, а не о
компьютере посетителя удалённого сайта. Ссылка в интерфейсе ведёт прямо в таблицу процессоров Hardware Museum
с колонками L1, L2 и L3: https://hw-museum.cz/cpu/cpu-interactive-table.
