# Проверка нового дизайна в Firefox

Запуск: `docker compose up --build`, затем http://localhost:18080.
Ширины — через режим адаптивного дизайна (Ctrl+Shift+M).
Тема — кнопкой ◐/☀/☾ в верхней полосе.

## Главная

- [ ] Название, подзаголовок, абзац о курсе.
- [ ] Карточки разделов: номер, название, строка описания; у раздела 20
      счётчик «0 из 3» (или сколько зачтено), у раздела 30 счётчика нет.
- [ ] Карточки «Triton Inference Server» и «LLM-сервинг» — пунктирные, не ссылки.

## Раздел «Python как рантайм сервиса»

- [ ] 1400px: три колонки; справа «На этой странице» подсвечивает текущее
      место при прокрутке; клик по пункту не прячет заголовок под полосой.
- [ ] 1000px: правой колонки нет, левая на месте.
- [ ] 390px: одна колонка, ☰ открывает и закрывает панель (Esc и клик по
      ссылке тоже закрывают); нет горизонтальной прокрутки страницы.
- [ ] Выноски «Боль сервиса №N» — серый фон, полоса слева, заголовок «Важно».
- [ ] Наведение на заголовок показывает «#»; у кода в тексте есть «Копировать».
- [ ] viz «Copy-on-write» и «Арены pymalloc» — карточки, кнопки работают.

## Блоки

- [ ] Замер (например, «PSS воркеров после fork»): «Замерить» → спиннер →
      график; цвета линий читаются в обеих темах; смена темы перекрашивает
      график.
- [ ] Задание: «Проверить» со стартовым кодом → «не хватило» (жёлтый бейдж,
      рамка нейтральная).
- [ ] Задание с синтаксической ошибкой → красная рамка, трассировка в
      прокручиваемом блоке.
- [ ] Зачтённое задание → зелёная рамка, крупное число, счётчик в левой
      колонке и ✓ у части справа обновились без перезагрузки.

## Прочее

- [ ] Приватное окно: страница работает, счётчики показывают 0, тема
      переключается (до перезагрузки).
- [ ] Тёмная тема: нейтральная, без синевы; редактор и графики тёмные.
