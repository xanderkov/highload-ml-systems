# Проверка раздела «LLM» в Firefox

Запуск: `docker compose up --build` (сборка runner скачивает llama.cpp и
модель GGUF ~0,7 ГБ), затем http://localhost:18080. Тема — кнопкой ◐/☀/☾.

## Навигация

- [ ] Главная: карточка «04 LLM: батч из шагов, а не из запросов» — ссылка;
      пунктирных карточек «скоро» больше нет.
- [ ] Раздел «Triton», подглава 6, «Мост к LLM»: «бонусной части» — ссылка на раздел LLM.
- [ ] Раздел LLM: внизу «← Предыдущий раздел» ведёт на Triton; «Следующего» нет.
- [ ] Справа «На этой странице»: подглавы 0–6 и подзаголовки подглавы 6
      (Prefill мешает чужому декоду, vLLM, SGLang, Итог курса).
- [ ] Таблица «Итог курса» читается на 390px (прокручивается внутри).

## Блоки

- [ ] «Шаг генерации при батче 1 … 32»: «Замерить» → 2 линии, лог-шкала, ~10 с.
- [ ] «Генерация без KV-кэша и с ним»: 3 линии, ~50 с.
- [ ] «По одному запросу против статического батча»: 3 линии, ~1 мин.
- [ ] Задание «Continuous batching»: «Проверить» со стартовым кодом → «не хватило»
      (goodput_ratio около 1). Эталон из `snippets/engine_ref.py` → зачтено, счётчик «1 из 2».
      Строка `batch.keep(keep[::-1])` вместо `batch.keep(keep)` → «не совпали с генерацией в одиночку».
- [ ] «Ваш движок против статического батча»: вставить свой движок из задания →
      4 линии, ваш TTFT низкий до 24 RPS; ~1,5 мин.
- [ ] «llama.cpp с 1, 4 и 16 слотами»: 3 линии, ~2 мин.
- [ ] «Выигрыш от батча: свой движок и llama.cpp»: 2 линии, ~20 с.
- [ ] Задание «Бюджет KV-кэша»: стартовые числа (8 слотов) → не зачтено, в выводе
      «ответов обрезаны». `SLOTS = 6` → зачтено, «2 из 2». `SLOTS = 9` → сообщение про 256 токенов.
- [ ] «Длинный промпт посреди чужой генерации»: 2 линии, у «по умолчанию» один пик ~1600 мс около 1–2,6 с.
- [ ] «vLLM под смесью подглавы 4» без запущенного vLLM: красная рамка и текст с командами
      `docker compose stop triton` / `docker compose --profile vllm up -d vllm`.
- [ ] Две вкладки, два замера раздела LLM (или LLM и Triton) одновременно: второй
      пишет «замер другого блока ещё идёт, ждём…» и отрабатывает после первого.
