## 2. Регистры и инструкции

Компилятор преобразует исходный код на C в машинный код — последовательность
инструкций, которые выполняет процессор. Эти инструкции загружают данные
из памяти, выполняют арифметические операции и управляют порядком выполнения
программы. Ассемблер — текстовая запись машинных инструкций, удобная для чтения
и анализа скомпилированного кода.

В этом курсе мы не будем изучать ассемблер целиком. Разберём только те
инструкции, которые нужны для понимания примеров и оптимизации кода.

Ниже используем синтаксис Intel для x86-64. В инструкциях `ADD` и `SUB` первый операнд указывает,
куда записать результат, второй — откуда взять значение для операции.

**Регистр** — небольшое хранилище внутри процессора для чисел, адресов
и промежуточных результатов. `RAX`, `RBX` и `RCX` — 64-битные регистры.
`EAX` и `EBX` — младшие 32 бита `RAX` и `RBX`; их используем для чисел типа `int`.

Рассмотрим функцию суммирования матрицы из первого задания. Для этого примера
заменим два вложенных цикла одним: матрица хранится в непрерывном участке
памяти, поэтому можно пройти по всем `n * n` элементам последовательно,
по строкам.

Слева — C, справа — соответствующие инструкции ассемблера.
Берём матрицу `2 × 2`: `n = 2`, массив `a` начинается по адресу `0x1000`.

В стенде выполняется тот же цикл: `EAX` — сумма, `RCX` — индекс,
`RDX` — количество элементов.

### Два порядка обхода

Оба варианта обходят всю матрицу `2048 × 2048` двумя вложенными циклами.
Перед запуском `RDI` содержит адрес массива. `RSI` — адрес текущего элемента,
`RCX` — счётчик внутреннего цикла, `RDX` — внешнего. Сумма хранится в `EAX`,
загруженный элемент — в `EBX`.

```viz id=traversal-comparison
```

Внутренний цикл `loop` читает 2048 элементов. Внешний цикл `outer` повторяет
этот проход 2048 раз. Слева адрес внутри прохода увеличивается на 4 байта,
а начало следующего прохода — на 8192. Справа эти шаги поменяны местами:
8192 байта между элементами столбца и 4 байта между началами столбцов.

В обоих вариантах одинаковые инструкции выполняются одинаковое количество
раз. Различаются только два шага адреса, выделенные в коде.
