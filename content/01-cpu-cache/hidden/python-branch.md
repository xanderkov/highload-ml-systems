## 5. Порядок данных в Python

В списке 4 194 304 числа: `−1` и `1`. Нужно сложить положительные значения.
В первом варианте числа перемешаны, во втором те же числа сгруппированы:
сначала отрицательные, затем положительные. Код функции одинаков в обоих вариантах.
Используется обычный Python, без NumPy и других библиотек обработки массивов.

Число итераций, проверок и сложений одинаково. В перемешанном списке результат
условия `x > 0` часто меняется, а в сгруппированном — меняется только один раз.

Показана медиана 11 запусков после двух прогревочных проходов.
Создание списка и группировка выполняются заранее, за пределами замера:

```python
grouped = (
    [x for x in data if x <= 0]
    + [x for x in data if x > 0]
)
```

Группировка тоже требует времени и дополнительной памяти. Для одного прохода
она может оказаться дороже полученного выигрыша. За сколько повторных обработок
она окупится, если исходные данные не меняются?

Этот пример показывает влияние порядка данных на выполнение Python-кода.
Это не изолированный замер предсказателя ветвлений: интерпретатор выполняет
собственные инструкции и переходы. Величина эффекта зависит от процессора
и версии Python.
