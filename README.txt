Курс: оптимизация программ

Запуск

1. Установите и запустите Docker с Docker Compose
   (например, Docker Desktop на Windows или macOS).
2. Распакуйте архив. Откройте терминал в папке cpu-course,
   где находится docker-compose.yml.
3. Выполните:

   docker compose up --build

4. Откройте http://localhost:18080
   Сразу откроется страница курса со всеми разделами.

Первый запуск требует интернета для загрузки образов и зависимостей.
Python, GCC, Node.js, NumPy и Numba на компьютере устанавливать не нужно.
Образы собираются под архитектуру компьютера, без принудительной эмуляции.
В Docker должно быть доступно хотя бы 4 ГиБ памяти; рекомендуется также не
меньше 4 процессоров.
В образ runner входит PyTorch (CPU), поэтому первая сборка заметно больше
и дольше обычной.
Задание 2 раздела «Python как рантайм сервиса» требует не меньше 4 процессоров
в Docker; на меньшем числе оно покажет сообщение вместо результата.
Время замеров зависит от компьютера и выделенных Docker ресурсов.
Тяжёлые блоки (задания 1 и 2 раздела «Python как рантайм сервиса») запускайте
по одному: одновременные запуски делят общий лимит памяти runner'а и
искажают замеры друг друга.

Остановка

Нажмите Ctrl+C, затем при необходимости выполните:

   docker compose down

Запуск в фоне:

   docker compose up --build -d

Если порт 18080 занят, создайте рядом с docker-compose.yml файл .env:

   COURSE_PORT=18081

После запуска откройте http://localhost:18081
