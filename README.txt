Высоконагруженные ML/DL системы
Почему мы используем Triton

Интерактивный курс о том, почему сервис с моделью на Python упирается под
нагрузкой не в модель, а в рантайм, протокол и обработку запросов по одному,
и что из этого снимает Triton Inference Server. Каждую проблему курс сначала
замеряет у вас на машине, потом чинит руками.

Запуск

1. Установите и запустите Docker с Docker Compose
   (например, Docker Desktop на Windows или macOS).
2. Откройте терминал в папке курса, где находится docker-compose.yml.
3. Выполните:

   docker compose up --build

4. Откройте http://localhost:18080
   Откроется главная страница курса со всеми разделами.

Первый запуск требует интернета для загрузки образов и зависимостей.
Python, Node.js и PyTorch на компьютере устанавливать не нужно.
Образы собираются под архитектуру компьютера, без принудительной эмуляции.
В образ runner входит PyTorch (CPU), поэтому первая сборка заметно больше
и дольше обычной.

Требования

В Docker должно быть доступно хотя бы 4 ГиБ памяти и не меньше
4 процессоров. Задания с несколькими воркерами и нагрузочные замеры
(разделы «Python как рантайм сервиса» и «Наивный сервис и свой батчер»)
на меньшем числе процессоров покажут сообщение вместо результата.
Время замеров зависит от компьютера и выделенных Docker ресурсов.
Тяжёлые блоки запускайте по одному: одновременные запуски делят общий
лимит памяти runner'а и искажают замеры друг друга.

Остановка

Нажмите Ctrl+C, затем при необходимости выполните:

   docker compose down

Запуск в фоне:

   docker compose up --build -d

Если порт 18080 занят, создайте рядом с docker-compose.yml файл .env:

   COURSE_PORT=18081

После запуска откройте http://localhost:18081
