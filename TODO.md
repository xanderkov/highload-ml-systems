# Темы для курса

- [ ] Рассказать о стоимости дополнительной индирекции: чтобы получить значение через указатель, может потребоваться ещё одно чтение памяти; зависимые чтения сложнее выполнять параллельно. Сравнить обход отдельных объектов по указателям с компактным массивом. Показать, как расположение обрабатываемых данных рядом помогает использовать кэш-линии и последовательное чтение. Подчеркнуть, что значение имеет расположение реально используемых данных; эффект проверить замерами, а не формулировать как безусловный запрет указателей.
