Высоконагруженные ML/DL системы
Почему мы используем Triton


1. Для работы необходим `docker`
2. `docker compose up --build -d`
3. Откройте http://localhost:18080
   Откроется главная страница курса со всеми разделами.

P.S.

В Docker должно быть доступно хотя бы 8 ГиБ памяти (runner — до 3 ГиБ,
Triton — до 4 ГиБ), не меньше 4 процессоров и около 20 ГБ места на диске.

vLLM (необязательно)

Один блок раздела «LLM» меряет сервер vLLM. По умолчанию он не запускается:
ему нужно около 6 ГиБ памяти (в Docker тогда должно быть доступно не меньше
12 ГиБ). 

Курс проверял его только в режиме bf16 на процессоре с AVX-512;
на процессорах без AVX-512 vLLM не проверялся. Чтобы запустить vLLM,
остановите Triton (они делят одни процессоры):

   docker compose stop triton
   docker compose --profile vllm up -d vllm

Первый старт скачивает модель с huggingface.co (около 1 ГБ) и занимает
пару минут. Вернуть всё как было:

   docker compose --profile vllm stop vllm
   docker compose start triton
